# Stack y áreas de conocimiento

## Soporte IT y operaciones
Soporte a usuarios y sucursales · diagnóstico de hardware, software, impresoras térmicas y periféricos · puestos de trabajo · ecosistemas POS · capacitación a usuarios no técnicos · documentación operativa

## Administración de sistemas e infraestructura
Windows Server y servicios · Hyper-V y máquinas virtuales · RDP · aplicaciones como servicios (NSSM) · Nginx como proxy inverso · FTP · certificados SSL (win-acme) · Cloudflare Named Tunnels

## Redes y conectividad
LAN · VPN y conectividad entre sucursales · routers, firewall, NAT y redirección de puertos · diagnóstico de conectividad · impresoras y balanzas en red

## Bases de datos y sistemas comerciales
MongoDB (administración, consultas, migraciones y precios POS) · PostgreSQL y Supabase (Auth, RLS, Connection Pooler) · Prisma ORM · SQLite · ecosistema Napse / Bridge POS

## Desarrollo y automatización
Python (Flask, pandas, numpy, openpyxl, PyMuPDF, ReportLab) · JavaScript y Node.js (Express, PDFKit, bwip-js) · TypeScript, React y Next.js (App Router) · Tailwind CSS · APIs REST · Git y GitHub · Docker y WSL/Ubuntu
